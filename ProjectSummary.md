Praxis Belli is a company-sized combined arms tabletop miniature wargame in 28mm/32mm heroic scale. It streamlines the rulesets common for grimdark wargames and replaces clutter with meaningful decision-making while reducing players' cognitive overhead. *(Earlier working title: "Iron Horizon," retired in favour of Praxis Belli — see `design-bible.md`.)*

# Core Design Tenants
1. Every decision should be made prioritizing an interesting gaming experience without adding complexity.
2. Onboarding to the game should be simple: "Easy to learn, impossible to master"
3. A regular-sized game should be played in about 2hrs from the first activation of the game; this assumes that both players are familiar with the rules. *(The exact standard-game point target is open — see `design-bible.md`'s Decision Queue; 2000 or 3000 points, to be set once the points formula is rebuilt for d6. No longer 1000.)*
4. Game mechanics should reward combined-arms playstyles without punishing players who have a strong preference for heavier reliance on certain elements. In other words, players should be given a set of asymmetric tools to use and its up to them to use them effectively against the challenges the scenario and their opponent throw their way.

# Project Goals
1. I want to self-publish through wargamesvault.com and set the price to pay-what-you-want so that others can enjoy my game and kick me a few bucks if they feel like it's worth it.
2. I want the game to feature several core factions, a scenario generator (with 5-10 standard scenarios), and a unit-building matrix for custom faction or unit building for players to create custom-yet-legal forces for the game.
